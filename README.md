# NuageGames

**Compara preços. Escolhe melhor.**

A NuageGames é uma plataforma de comparação de preços de videojogos digitais e físicos. O objetivo é ajudar os jogadores a encontrar os melhores preços em diferentes lojas, sem necessidade de visitar cada loja individualmente.

## 🎮 Plataformas suportadas

- PC
- PlayStation
- Xbox
- Nintendo

## 🎯 Objetivos do projeto

- Comparar preços de videojogos em várias lojas.
- Apresentar os preços do mais baixo para o mais alto.
- Permitir filtrar jogos por plataforma.
- Disponibilizar pesquisa por nome do jogo.
- Redirecionar os utilizadores para as lojas onde podem comprar.
- Expandir inicialmente em Portugal e, futuramente, internacionalmente.

## 💻 Tecnologias

Tecnologias previstas para o desenvolvimento:

- HTML5
- CSS3
- JavaScript
- Node.js (backend futuro)
- API de fornecedores de preços (futuro)

## 🚀 Como executar

### Versão inicial

1. Descarregar ou clonar o projeto.
2. Abrir a pasta `NuageGames`.
3. Abrir o ficheiro `index.html` num navegador.

Se o projeto passar a utilizar um servidor local, as instruções serão atualizadas.

## 🔒 Segurança

- Não publicar ficheiros `.env`.
- Não colocar chaves privadas no frontend.
- Utilizar fontes de preços autorizadas.
- Identificar claramente ligações de afiliados.
